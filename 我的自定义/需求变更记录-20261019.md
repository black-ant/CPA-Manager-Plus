## 一、账号卡片 UI 重构（AccountsPage）

### 1. 配额窗口卡片：三行 → 两行
- 原三行结构（标题行「月限额 / 剩余 xx%」、进度条、用量行）合并为两行：
  - 第一行：`月限额  [$已用/Token] [$预测] [29天后] …… 剩余 xx%`
  - 第二行：进度条
- 重置时间不再独占右侧（`margin-left: auto` 改由百分比承担）
- 紧凑模式（简略/Compact）同步改为两行
- 涉及文件：`apps/web/src/features/accounts/AccountsPage.tsx`、`AccountsPage.module.scss`

### 2. 仅一个配额窗口时卡片铺满
- 网格卡片视图 `.accountGridCardQuotaList` 补充 `:only-child` 规则（`grid-column: 1 / -1`），与列表视图行为对齐
- Antigravity 分组模式下只有一个分组时同样铺满

### 3. 用量行单行不换行
- `quotaWindowUsageLine` 改为 `flex-wrap: nowrap`，徽章可收缩，数值放不下时省略号截断
- 图标、斜杠、重置时间保持 `flex-shrink: 0`

### 4. 最近状态区域合并为一行
- 原「最近状态」标题行 + 状态条行合并：
  `最近状态  [状态条] 100%  ●成功数 ●失败数`
- 状态条 `flex: 1` 弹性伸缩，计数徽章固定右侧
- 卡片高度不变（用户确认当前高度可接受）

### 5. 卡片区背景色对比
- `.tablePanel` 面板底色由与卡片相同的白色改为更深一档的冷灰：
  - 浅色主题：`color-mix(in srgb, var(--app-bg) 91%, var(--app-text-primary))`（约 `#dde2e8`，用户要求比最初的 86% 更浅）
  - 深色主题：直接使用 `var(--app-bg)`，比卡片更暗
- 仅影响账号页面板，其他页面不受影响

## 三、构建与部署（Docker / Ant-Windows-Bat 工作流）

### 1. 镜像 tag 对齐
- 问题：部署脚本默认拉取 `:myself` tag，但该 tag 从未被推送，导致 `manifest unknown` 拉取失败
- 修复：所有脚本默认镜像统一为 `...:latest`
  - `CliProxyAPI/cliproxyapi_deploy.sh`
  - `CliProxyAPI/cpa_manager_ui_deploy.sh`
  - `CliProxyAPI/config.json`（3 处变量默认值）

### 2. 修复「服务器打包镜像」脚本 bug
- `cpa_manager_build_push_images_remote.sh` 的 `require_value()` 中
  `is_placeholder "$value" && fail ...` 在值**合法**时函数返回 1，触发 `set -e` 静默退出
- 现象：脚本 2 秒内无任何输出地失败，面板提示"未捕获到具体错误信息"
- 修复：改为 `if is_placeholder "$value"; then fail ...; fi`

### 3. Ant-Windows-Bat 工作流条目精简
- 移除与「最新版」完全重复的「CliProxyAPI 一键部署配置（稳定版）」条目
- 移除独立的「CPA-Manager Plus UI 部署」条目（一键部署已包含，`DEPLOY_CPA_MANAGER=yes`）
- 保留 2 个步骤：①一键部署配置（v8.0.31-最新版） ②服务器打包镜像

### 4. Dockerfile 构建参数
- `Dockerfile.manager-server` 透传 `NODE_OPTIONS` / `GOPROXY` 构建参数
- `docker-compose.manager.yml` 改用阿里云 ACR 镜像
